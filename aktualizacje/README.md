# Katalog aktualizacji

Zasady:
1. Każde wdrożenie na produkcję = nowy plik `NNN_RRRR-MM-DD_krotka-nazwa.md`, numeracja rośnie o 1 (nie zmieniamy starych numerów).
2. W pliku: data wdrożenia, commit, lista zmian, numery migracji bazy.
3. Po dodaniu pliku dopisz wiersz w `INDEKS.md`.
4. Plik powstaje przed wdrożeniem i trafia do tego samego commitu.
